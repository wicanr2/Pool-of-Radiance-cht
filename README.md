# 光芒之池 Pool of Radiance 繁體中文重製版

SSI 在 1988 年推出的《Pool of Radiance》，以 Go／Ebitengine 重寫、全程繁體中文，
可在 Linux、Windows 與 macOS 上執行。規則、腳本與畫面以原版 DOS 版為準，
從建立隊伍一路玩到結局；遊戲內 1,731 句文字全部翻成中文，用詞取自軟體世界代理當年的
官方中文說明書。

原版遊戲資料與中文字型都不隨本專案散布，需要自己準備（見[下載與準備](#下載與準備)）。

## 遊戲介紹

《Pool of Radiance》（光芒之池）是 SSI 取得 TSR 授權、依《進階龍與地下城》（AD&D）規則
製作的電腦角色扮演遊戲，也是後來被稱為「金盒子」（Gold Box）系列的第一款。舞台在
被遺忘的國度（Forgotten Realms）的月之海（Moonsea）北岸。當年台灣由軟體世界代理，
附上兩冊中文說明書：上冊「探險者手冊」、下冊「操作手冊」。

玩家不扮演單一英雄，而是帶領一支最多六人的冒險隊伍：

1. 從種族、性別、職業、陣營擲出六項屬性，建好每一位隊員，自訂肖像與戰鬥造形。
2. 以第一人稱走迷宮式的街區與地城，隨時可以打開平面圖。
3. 遇敵時轉到俯視的戰術盤面，隊員逐一移動、攻擊、施法，走位與隊形都會影響勝負。
4. 在市政廳接下議會的委任，一區一區收復舊城，推進主線。
5. 回到城裡的旅店、神殿、商店與訓練所休息、治療、買賣與升級；紮營時記憶法術、存檔。

## 故事

以下摘自探險者手冊第二章〈被遺忘的傳說〉。

### 月之海與菲蘭城

月之海夾在瓦薩山脈與諾曼大草原之間，是南方文明與北方荒原的交界。南方王國的人被半獸人、
飛龍圍攻時，常自我安慰說：「至少比月之海沿岸好得太多了。」

菲蘭城位在月之海北岸，巴蘭河從北方流進城裡，數百年前它曾是月之海第一大城。傳說精靈最先發現了
「光芒之池」：一池因自身魔力而閃閃發光的水，會為有資格的人帶來巨大的力量，也會為沒有
資格的人帶來最可怕的死亡。池子的位置在每個傳說裡都不一樣，許多智者乾脆說它只是神話。

### 一次次的興衰

山谷紀元 712 年，麥爾瑟·瓦傑渥在巫師里蒙與提爾的亞蘿妮絲公主協助下重建菲蘭，趕走盤據
城中的半獸人，也把上古巫妖查納卡逐出古托湖中央的巫師之島。瓦傑渥王朝讓菲蘭成為月之海的
貿易中心，繁榮了兩百多年，之後在饑荒、內戰與外敵之間一路衰落，王室血脈斷絕，權力落到
商人組成的議會手上。

五十年前，一支有飛龍助陣的大軍從北方湧來，議會迎戰失敗，菲蘭被焚毀，落入邪惡勢力手中。
最後一位提爾的牧師費瑞·馬提茲死守河口的索卡爾城堡，據說他對城堡下了可怕的詛咒。
河水從此變得混濁有毒，原本肥沃的河谷成了「被洗刷過的土地」。巫師之島據說被黑暗法師
亞拉斯佔據，他在追尋里蒙的力量、上古巫妖的秘密與光芒之池。

### 議會的召集令

兩年前的蠕蟲之年，一大群飛龍從遙遠的北方南下，沿途摧毀一切。盤據菲蘭廢墟的邪惡將領們
首當其衝，權力因此出現真空，菲蘭人終於有機會回來重建。

倖存議員的後代重組了菲蘭議會。他們沒有偉大的法師或戰士，只有商人與牧師，於是決定照
瓦傑渥當年的做法：**招募冒險者清理舊城**。議會發出告示，付錢請吟遊詩人把故事傳遍月之海
沿岸，許下鉅額財富，還有「通往光芒之池之路的秘密」。

### 你的隊伍

玩家的隊伍搭船抵達新菲蘭城。這座城只是廢墟中一塊用柵欄圍起來的據點，城牆上的警衛日夜
巡守，隨時準備擊退舊城那一側的攻擊。城裡擠滿了前來碰運氣的冒險者，和想重建貿易線的商人。

柵欄外的貧民窟、古托井、瓦海登墳場、曼多爾圖書館、索卡爾城堡與瓦傑渥城堡，都還在怪物與
邪惡勢力手裡。舊城的怪物似乎都聽命於同一個主子，牠們提起他時只稱「老大」。

## 這個重製版多了什麼

- **全程繁體中文**：敘事、對話、選單、物品、法術、戰鬥訊息都已中文化，譯名照軟體世界的
  官方說明書。`F7` 可以隨時切換成英文。
- **探險者手冊收進遊戲**：原版常在畫面上只給一個編號，要玩家翻紙本手冊。這裡遊戲文字一報
  編號，按繼續就直接翻到那一則；`J` 也能隨時翻閱。手冊附錄的規則表（法術、裝備、武器、
  升級經驗）也在裡面。
- **遊戲內攻略（`F3`）**：每張地圖的重點位置，座標取自原版地圖資料。預設只顯示走過的格子，
  想看全貌按 `V` 攤開。
- **密語提示**：原版有 20 處要玩家打字回答（守衛的口令、亡魂的暗語、矮人符文），答案藏在
  幾十格之前 NPC 說的話或說明書裡。重製版預設把答案接在問句後面，不想要可以關掉。
- **配樂**：原版 DOS 版只有喇叭音效。重製版可以播 PC-98 版或 Amiga 版的原版配樂，
  但配樂有第三方著作權，不隨發行包附上（見 [`packaging/README-配樂.md`](packaging/README-配樂.md)）。
- **可選的輔助**：現代配色（`F2`）、自訂規則「委任經驗值加倍」（人物管理選單的 `H`）、
  作弊選單（`F6`：鎖 HP、一擊斃命、穿牆）。三者預設都關；開過作弊會記在存檔上。

## 下載與準備

到 [**最新發行版**](https://github.com/wicanr2/Pool-of-Radiance-cht/releases/latest) 下載：

| 平台 | 檔案 |
|---|---|
| Linux | `…-x86_64.AppImage` |
| Windows | `…-windows-x86_64.zip` |
| macOS（Apple Silicon／Intel） | `…-macos-arm64.zip`／`…-macos-x86_64.zip` |

發行包**不含原版遊戲資料，也不含中文字型**，兩者都沒有公開散布權，要自己準備：

1. **原版遊戲**：把自己合法持有的 DOS 版遊戲檔打包成 `Pool of Radiance (1988).zip`，
   放在執行檔或 AppImage 同一層（ZIP 內保留原始的 `poolrad/…` 目錄）。放在別處就用
   `-zip <路徑>` 指定。
2. **倚天字型**：倚天中文系統的 `stdfont.15`，用 `-eten-font <路徑>` 指定；同一層有
   `ascfont.15`、`spcfont.15` 會一併使用。

```sh
./pool-of-radiance-remake-<版本>-x86_64.AppImage -eten-font /path/to/stdfont.15
```

沒有字型時 `-lang zh` 會直接結束並說明原因，不會默默改用英文。存檔寫到作業系統的使用者
設定目錄（`pool-of-radiance-remake/state.json`），可用 `-save <路徑>` 改位置。其餘參數見
發行包裡的 `README.md`。

## 操作說明

整個遊戲只用鍵盤。遊戲中隨時按 `F1` 可以看說明頁。

### 標題與人物管理

標題畫面按 `ENTER` 或空白鍵進入人物管理選擇項：

| 鍵 | 功能 |
|---|---|
| `C` | 創造新人物 |
| `A` | 將人物加入隊伍（隊伍最多六人） |
| `R` | 把隊員移回人物名單 |
| `V` | 檢視人物 |
| `M` | 重新調整屬性（只限經驗為 0、身上除了錢沒有別的物品的人物） |
| `D` | 永遠除掉人物 |
| `T` | 訓練升級（只在訓練所裡出現） |
| `L` | 叫出存下的進度 |
| `S` | 存下目前進度 |
| `B` | 開始冒險 |
| `H` | 自訂規則：委任經驗值加倍（預設關） |
| `E` | 跳回 DOS（結束遊戲） |

### 建立人物

1. 種族、性別、職業、陣營：上下鍵選，`ENTER` 確定，`ESC` 回上一步。
2. 人物資料頁：擲出的屬性不滿意就按 `R` 重擲，滿意按 `ENTER` 或 `Y` 保留。
3. 輸入姓名，按 `ENTER`。
4. 肖像：`H` 換頭部、`B` 換身體、`K` 決定。預設肖像會依性別與職業挑選。
5. 戰鬥造形：方向鍵選部位、顏色與大小，`ENTER` 確定；選「離開」之後按 `Y` 確認，人物就建好了。

### 冒險畫面

| 鍵 | 功能 |
|---|---|
| `↑` | 往前走一格 |
| `←` `→` | 向左、向右轉 |
| `A` | 平面圖（再按一次回到第一人稱） |
| `C` | 施法 |
| `V` | 檢視隊員的資料頁 |
| `E` | 紮營 |
| `S` | 切換邊走邊搜（再按一次關掉；搜尋會花時間） |
| `L` | 搜尋周遭一次，效果不持續 |
| `I` | 裝備或卸下物品 |
| `J` | 探險者手冊 |
| `K` | 法術一覽 |
| `ENTER` | 事件文字的下一頁、確定選項 |

### 紮營（`E`）

| 鍵 | 功能 |
|---|---|
| `S` | 存檔 |
| `V` | 檢視隊員 |
| `M` | 記憶法術（選好之後要休息才記得起來） |
| `R` | 休息，回復生命力並記住法術；休息可能被怪物打斷 |
| `A` | 調整：隊伍順序、除名、遊戲速度、圖片開關、戰鬥造形 |
| `E` | 離開營地 |

### 戰鬥

遇到怪物時可以選擇戰鬥、等待、逃跑或交涉。進入戰術盤面後，輪到誰就指揮誰：

| 鍵 | 功能 |
|---|---|
| `M` | 移動，接著用 `H I M Q P O K G` 或數字鍵盤指定八個方向 |
| `A` | 瞄準並攻擊 |
| `C` | 施法 |
| `U` | 使用物品 |
| `T` | 牧師轉變不死生物 |
| `B` | 替倒下的隊員包紮 |
| `D` | 延後行動 |
| `ENTER` | 結束這名隊員的回合 |
| `Q` | 自動戰鬥，交給電腦指揮；`SPACE` 收回 |

最下面那一列只顯示這名隊員能用的指令：身上沒有物品就沒有「使用」，沒記法術就沒有
「施法」。敵人全倒之後會問要不要繼續戰鬥，答 `N` 結束。

### 功能鍵

| 鍵 | 功能 |
|---|---|
| `F1` | 說明頁（`←` `→` 翻頁） |
| `F2` | 原版／現代配色切換 |
| `F3` | 這張地圖的攻略（`V` 攤開全貌） |
| `F4` | 素材總覽（`TAB` 翻頁） |
| `F5` | 戰術盤面示範 |
| `F6` | 作弊選單（原版沒有；`P` 開關密語提示） |
| `F7` | 切換繁中／English |
| `F10` | 存檔並離開 |
| `Ctrl+O` | 開關音樂 |
| `ESC` | 回上一頁 |

## 目前進度

以「完整繁中、正常主線可破關、三平台可發行」為分母，目前估計 **89～93%**：

- 遊戲內文字 1,731 句全部翻完，介面沒有缺字。
- 從標題到結局已經只用鍵盤連續跑通。驗收那一趟開了作弊選單的鎖 HP 與一擊斃命，原版那一側
  同樣作弊跑一次，兩邊逐段對照必經的腳本區塊與旗標。
- 發行包與原版 DOS 畫面抽樣對拍 36 張，全部量到：標題 99.79% 相同（差的是重製版自己加的
  按鍵提示），第一人稱框逐格 100% 相同。[對拍報告](docs/audit/dos-parity-sample.md)
- Linux 與 Wine 實測可以啟動；**Windows 與 macOS 的真機啟動還沒驗收**
  （[#6](https://github.com/wicanr2/Pool-of-Radiance-cht/issues/6)），這是目前壓住上限的一項。

量法、各子系統照原版哪一段做、和不追的項目，見[技術總覽](docs/technical-overview.md)。

## 給開發者

這個 repository 公開原始碼與發行包，但 clone 下來無法直接建置：`go.mod` 依賴私有的共用
引擎 [`golden-box-remake-engine`](https://github.com/wicanr2/golden-box-remake-engine)，
沒有存取權時 `go build` 會停在抓不到模組那一步。想玩請直接下載發行版；想讀程式碼、回報問題
或提修正建議都歡迎，需要建置權限請來信洽談。

所有分析、建置與測試都在 Docker 裡跑：

```sh
tools/go.sh test ./...
```
