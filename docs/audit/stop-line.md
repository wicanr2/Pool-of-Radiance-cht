# 停止線：不追的項目

依 AGENTS.md §11〈收斂標準〉（使用者 2026-09-27 決定：只追影響玩法的項目），下列項目
不當成工作，也不開 issue。每一條寫明不追的理由；日後若證明它其實影響玩法，
從這裡搬回 GitHub issue，並在這一列註明搬走的日期與編號。

分類：

- **呈現**：動畫、音效、停拍時機與長度、訊息列位與顏色、版面像素差。規則狀態不變。
- **未知**：證據停在 `unknown`／`hypothesis`，玩家看不出差別。
- **收據**：規則已有位元組證據與送鍵測試，缺的只是另一份原版執行期收據。
- **無觸發**：規則讀到 exact，但原版資料裡沒有任何一筆會走到會改變結果的分支。
- **罕見觸發**：會改變結果，但只在玩家主動做出原版不鼓勵的操作時才走得到，且受影響的遭遇極少；寫明觸發條件，主線不受影響。
