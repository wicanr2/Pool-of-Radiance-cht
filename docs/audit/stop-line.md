從這裡搬回 GitHub issue，並在這一列註明搬走的日期與編號。

分類：

- **呈現**：動畫、音效、停拍時機與長度、訊息列位與顏色、版面像素差。規則狀態不變。

- **無觸發**：規則讀到 exact，但原版資料裡沒有任何一筆會走到會改變結果的分支。
