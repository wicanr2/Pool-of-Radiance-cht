# Spec 078：`29h ENCOUNTER MENU`

狀態：CONFORMED（運算元陣列的版面、四個選項的字面、運算元 1／2／3／4／
5..9／13／14 的取用位置、結果寫回 ECL 變數的機制）；DRAFT（運算元 10..12、
`0045h:0043h` 的擲值規則、四個選項各自的後續、`4933h+1CCh` 那個條件）。
日期：2026-09-03。

## 為什麼先讀它

只用按鍵從標題走出去（`TestNormalKeysReachTheFirstDungeonStep` 的路徑再往下
走），隊伍會搭船抵達索寇要塞（archive 4、block 21），然後停在

```
continue Pool SearchLocation: opcode 0x29 at 1288 has no core handler or adapter passthrough
```

同一條路上隨機走 4000 步，**一次戰鬥都沒觸發**。這條 opcode 是目前主線最前面
的攔路石。

## 運算元怎麼存

取運算元的常式是 overlay-07 entry 2（code `0000h`）。ECL 的 PC 放在
`DS:494Eh`，指令位元組從 `[DS:493Fh] + 6700h` 讀。每個運算元 `i`（1 起算）
拆成三個平行陣列：

| 陣列 | 位址 | 內容 |
|---|---|---|
| 型別 | `DS:6DCBh + i` | 型別碼；1、2、3 表示後面還有一個高位元組 |
| 低位元組 | `DS:6E4Bh + i` | 值的低 8 位 |
| 高位元組 | `DS:6E0Bh + i` | 值的高 8 位（只有型別 1..3 才有）|

`0045h:0025h` 回傳低位元組；要 16 位的值就自己把兩個陣列合起來
（`0045h:0052h` 就是 `(高 << 8) | 低`）。

## 十四個運算元

`20B1h` 開頭 `mov al, 0Eh / lcall 0045h:002Ah` 一次取 14 個。

| 運算元 | 取用處 | 用途 |
|---:|---|---|
| 1 | `20E4h` → `DS:6D47h` | 怪物名稱索引，交給描述字串常式 |
| 2 | `20EFh` → 記錄 `+580h` | 數量上限 |
| 3 | `2100h` → `DS:6D48h` | 第二個名稱索引 |
| 4 | `210Bh`／`210Fh`（直接讀兩個陣列）| **結果要寫進哪個 ECL 變數**（16 位位址）|
| 5..9 | `212Dh` 的迴圈 → `[bp-6+i]` | 五格結果表，用選單的選擇當索引 |
| 10..12 | 這支常式沒有直接讀 | 未讀 |
| 13 | `2189h` | 門檻，`23EEh` 拿它和另一個值比 |
| 14 | `2195h` | 未讀 |

## 選單就是金盒子那四個選項

字面常數就放在常式前面：

| 位址 | 字串 |
|---|---|
| `2054h` | `~COMBAT ~WAIT ~FLEE ~PARLAY` |
| `2070h` | `~COMBAT ~WAIT ~FLEE ~ADVANCE` |
| `208Dh` | `Both sides wait.` |
| `209Eh` | `The monsters flee.` |

`~` 標的是快速鍵。`2333h` 決定用哪一版：記錄 `+582h` 為零，或
`[DS:4933h] + 1CCh` 為零，就用 PARLAY 那一版，否則用 ADVANCE。
選單輸入走 `0045h:0089h`（overlay-07 entry 21）。

`+582h` 由 `0045h:0043h(DS:6A0Bh, 6A0Ch, 6A0Dh)` 擲出來，再夾到運算元 2 給的
上限；`0045h:004Dh` 拿名稱索引與這個值組出描述字串放到 `DS:828Eh`。

## 結果寫回 ECL 變數

選完之後：

```
23BC  di = 選擇
23C3  al = [bp-6+di]          ; 五格結果表
23D0  結果 = 0 → 23D5
23D5    選擇 ≠ 2 → Store(運算元4, 1)
23EA    選擇 = 2 → 比門檻（運算元 13），寫 2 或 1
2413  結果 = 1 → 另一條路
```

`0045h:0070h`（overlay-07 `0C93h`）不是跳位，是**寫 ECL 變數**：它先用位址
分出三個記憶體區（`DS:4933h`／`4937h`／`493Bh`）再把值寫進去。所以這條
opcode 對 ECL 的可見效果就是「把一個結果碼寫進運算元 4 指的變數」，
後面的 `COMPARE`／`IF` 再據此分支。

## 還不能實作

四個選項各自的後續、結果碼 1 與 2 的意義、運算元 10..12 與 14 都還沒讀。

與正確處理它，在測試報表上分不出來（配
`~/diagnosis-notes/docs/03-silence-is-not-success/`）。現在的行為是硬失敗，
