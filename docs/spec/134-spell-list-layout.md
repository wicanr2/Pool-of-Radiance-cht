## 標題的七個句尾

同一支介面（overlay-19 entry 12，spec 119）依 `[bp+10h]` 換句尾：

| 值 | 句尾 | 什麼時候 |
|---|---|---|
| 0 | `in Memory` | `C)AST`：已記憶的法術 |
| 1 | `in Spell Book` | `MEMORIZE`：法術書（上圖就是這一種）|
| 2 | `on Scroll` | 抄一張卷軸 |
| 3 | `on Scrolls` | 抄多張 |
| 4 | `to choose from` | 學新法術 |
| 5 | `to be memorized` | 已排入記憶佇列的 |

**版面是同一份**，只有標題那一行的句尾與指令列不同。所以拍得到 `MEMORIZE`
那一種就等於拍到了 `C)AST` 那一種。

## 那一列不是版面

y 120..127 那一列在畫面上是一串看不懂的白色字元（色號 15 占 262／320）。
**不要照著畫**：那是未初始化緩衝被顯示出來，dosgolem 上的內容與真機不會
一樣（同一個位置在別的畫面也出現過同樣的雜訊）。原版那裡實際上放什麼
還沒讀出來。

## 怎麼走到

```
建人類牧師 → 開始冒險 → 導覽走完 → E（紮營）→ M（MAGIC）→ M（MEMORIZE）
```

完整鍵序（`tools/dosgolem-reference.sh` 的 `POOL_DOSGOLEM_KEYS`）：

```
rep:9:Space,Return,Return,c,rep:5:End,Return,Return,Return,Return,Return,
Return,y,H,E,R,O,Return,k,e,y,a,a,e,b,rep:18:Return,e,m,m
```

`rep:5:End` 是把種族清單的反白從 `DWARF` 移到 `HUMAN`——**清單用 End／Home
移動，不是 Down／Up**（spec 133）。

**原版的 `C)AST` 那一種還沒拍到**：一級牧師沒有記憶法術，要先休息讓
`MEMORIZE` 生效，而貧民區休息一定會被城市守衛打斷
（`YOU ARE ROUSTED BY THE CITY WATCH…`，見 spec 114）。那一段留給接上
「休息被打斷」之後再走。

## 兩種座標，不要混用

`drawText` 的 `Row` 參數是**基線**：字畫在 `Row-14 .. Row-1`。所以上表量到的
「文字最後一列 native `n`」對應的常數是 **`2n+2`**，不是 `2n`。繩索橫條給的
是**圖塊左上角**，那個直接 `2n`（native 16 的圖塊畫出來是 17..22）。

兩者混用的症狀是整頁文字往上跑一個 native 像素——測試全綠、截圖看起來也對，
要把實拍的色號逐列量出來才看得到。

## remake 現況：逐列與原版相同

挑法術那一步是整頁（`drawSpellPage`）：標題、繩索橫條、縮排的清單、再一條
繩索橫條、底下「還施得出來」，指令列在框外。這一頁的面板從 native 8 起，
**蓋掉 remake 自己那一行頁首**——原版這一頁沒有它。挑人那一步維持在下方
小框，那一步是 remake 自己加的（原版對「目前角色」施法，spec 119）。

## remake 怎麼走到（截圖流程）

`tools/capture-chinese-menu.sh` 建的是**人類牧師**（種族清單按五次 `End`
到人類，人類的職業清單第一個就是牧師），走完導覽之後：

```
K（法術一覽）→ TAB 到神術第 1 級 → M 記祝福術 → K 關閉
E（紮營）→ H 選小時欄 → I 加兩小時 → R 休息
C（施法）→ ENTER 挑施法者 → 這一頁
```

**走得到這一頁本身就是閘門**：建的不是施法職業、`M` 沒記進去、或休息時間不夠
讓它 ready，按下去都只會得到「沒有記憶法術」，截圖腳本會停在 `field-cast`。

法術一覽的組別也報進畫面識別字（`spells-cleric-1`／`spells-magic-user-1`），
因為翻組只換內容不換畫面——先前那三次 TAB 是盲按，掉一次鍵就拍到神術第 3 級，
而畫面上白紙黑字寫著別的級別卻沒有任何一步失敗。

**原版那一側的 `in Memory` 仍未拍到**：一級牧師沒有記憶法術，要先休息讓
`MEMORIZE` 生效，而貧民區休息一定會被城市守衛打斷（見 spec 114）。remake
這一側拍到的就是 `in Memory` 那一種；版面同一份，所以版面已經對得起來。
