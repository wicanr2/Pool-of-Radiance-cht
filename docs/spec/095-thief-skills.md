# Spec 095：角色記錄的八個賊技能

狀態：READY（偏移、順序與數值由預設人物與規則書雙向釘住）；
DRAFT（產生端——原版沒有任何 overlay 寫這八格）。日期：2026-09-03。

## 位置與順序

記錄 `+77h` 起八個位元組，每個是百分比：

| 偏移 | 技能 |
|---|---|
| `+77h` | 掏包 |
| `+78h` | 開鎖 |
| `+79h` | 找／解陷阱 |
| `+7Ah` | 潛行 |
| `+7Bh` | 躲影 |
| `+7Ch` | 聽聲 |
| `+7Dh` | 爬牆 |
| `+7Eh` | 讀語言 |

## 怎麼釘住的

預設人物裡只有 `chrdatd4`（TINA，職業碼 6 ＝ 賊，賊等級 `+9Ch` ＝ 9）
這八格非零，其餘六名全是 0：

```
80 / 77 / 65 / 80 / 66 / 30 / 98 / 45
```

規則書第 9 級賊那一列是 `80 / 77 / 65 / 78 / 63 / 30 / 97 / 45`——
**五項到個位數相同**，另外三項高 1..3，是敏捷與種族修正。
兩個最有辨識度的值（爬牆接近 97、讀語言 45）都落在對的位置，
所以順序也一併定下來。

## 誰讀它

目前只有 `1Eh CHECKPARTY` 的 `6BA7h` 模式（spec 092），它統計整隊的
**找／解陷阱**（`+79h`）的最小值、最大值與平均——正是踩到陷阱之前該問的
那件事。

四種寫入版面在 38 顆 overlay 與 START.EXE 裡都掃過，**零命中**，
所以這八格是隨記錄檔載進來的，遊戲執行期間沒有人改它。

## remake 現況

存檔的 `Character.ThiefSkills` 收這八格。remake 還沒有賊技能的產生端
（建角不寫、升級不寫），非賊本來就是 0，所以 `CHECKPARTY` 目前一律得到
0／0／0——**那是正確答案，不是佔位**。接上建角的賊技能之後這條就會動。
