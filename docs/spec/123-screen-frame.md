# Spec 123：畫面外框的繩索花紋

狀態：CONFORMED（三個符號的來源、四個角與上下左右的位置、外框停在第 23 列
tile，都以原版截圖逐格對過並照接）；DRAFT（`117h`..`11Eh` 那八個木條件是誰
在用、第一人稱框以外的其他框線）。
日期：2026-09-06。

## 那圈繩索是三個 8×8 符號

不是畫出來的線，是全域第 4 帶（`8X8D1.DAX` **區塊 202**，符號 `100h..11Eh`，
spec 120）裡的三個 item 拼出來的：

| 符號 | item | 用在哪 | 像素（EGA 索引）|
|---|---:|---|---|
| `114h` | 20 | 四個角的結 | `E`／`F`／`6`（黃、白、棕）|
| `115h` | 21 | 左右兩欄（直的繩子）| `0`／`C`／`4`（黑、亮紅、暗紅）|
| `116h` | 22 | 上下兩列（橫的繩子）| 同上 |

```
114h（角）        115h（直）        116h（橫）
EEEEEEEE          0C400C40          00000000
EFFFFF6E          0C400C40          CC0000CC
EFEEEE6E          0C40C400          44CC0C44
EFEF6E6E          00C0C400          004CC000
EFE66E6E          000C4000          0004CC00
EFEEEE6E          00C40400          C44004CC
E666666E          00C40C40          40000044
EEEEEEEE          0C400C40          00000000
```

`115h` 與 `116h` 是同一條繩子的兩個方向：那三格 `C4` 每列往旁邊挪一格，
接起來就是斜的纏繞。

**怎麼找到的**：先從原版截圖量出一格花紋（截圖的 PNG 調色盤是縮減過的，
要先換算回 EGA），再掃所有 DAX 的每一個區塊逐格比對——整包只有
`8X8D1.DAX` 區塊 202 命中，位置是 pixel row 176 ＝ item 22。
**掃全部比猜哪一個檔快**，而且命中只有一處，不會挑錯。

## 位置

320×200 切成 40×25 的 tile 網格。外框佔**第 0 列與第 23 列、第 0 欄與第 39 欄**：

```
tile 列 0   ：y =   0.. 7   角 116h×38 角
tile 列 1..22：x = 0..7 與 312..319 是 115h
tile 列 23  ：y = 184..191  角 116h×38 角
tile 列 24  ：y = 192..199  **空的**
```

最後一列是空的這件事要記著：200 ÷ 8 ＝ 25 列，外框卻停在第 23 列。

**它是整個遊戲共用的畫面框**，不是某一個畫面的裝飾——空隊伍選單、有隊伍
選單、Rolf 的半身像、自由移動、貧民窟五張截圖上逐格相同。

## 第一人稱那一框也是同一圈

外框 native `(16,16)..(119,119)`，內部 88×88 從 `(24,24)` 起——
也就是**內容外面一圈 tile**。四個角一樣是 `114h`。
這正好和 spec 047 量出來的 `StageInset{24,24,88,88}` 對得起來：
框的內緣就是 inset 的外緣。

畫面上還有第三圈：`y = 128..135` 有一條**貫穿整個寬度**的 `116h`，
那是文字框上面的分隔線。

## 還沒讀

- 第 4 帶剩下的八個 item（`117h`..`11Eh`）是一組**木條**：
  `117h` 左端、`119h` 中段、`118h` 右端是橫的；
  `11Ch` 上端、`11Eh` 中段、`11Dh` 下端是直的。畫面上還沒對到它們在哪，
  多半是選單或面板的框。
- 誰在什麼時候畫這一圈（開機一次？每次換畫面？）。

## remake 這一側

`cmd/pool-game/screen_frame.go`：

- `(*app).drawFrame` 畫畫面外框，用的就是上面那三個 item 與那個位置。
  band 4 沒載進來時退回原本那圈素色方框（`drawPlainFrame`），畫面不會空掉。
- `(*app).drawRopeBox` 是同一套符號圍任意一個框，第一人稱那一框用它。
- `TestScreenFrameSymbolsMatchTheDOSShot` 拿 `8X8D1.DAX` 區塊 202 的三個 item
  去對原版截圖上四個角、上下兩列、左右兩欄的實際像素，並確認第 24 列是空的。

**底部文字跟著往上移**：外框下緣那一列 tile 在邏輯 `y 368..383`，
所以頁尾與指令列的基線從 386 改成 366（ascent 14，字頂 352）。
原版最下面那一列文字在 native `y 168..174`，換算成邏輯是 336..348，
也在框上面——方向是一致的。

**第一人稱那一框的絕對位置仍與原版不同**：原版的視野在畫面上方
（native 頂端 16），remake 上面還有一列標題。那屬於整體版面，不在這一項裡。
