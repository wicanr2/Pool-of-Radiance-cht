## 派發（overlay-03 `1EA4h`，3 個運算元）

```

1EBDh  百分比 = 運算元 2 的值

       否則：從 5CF4h 走隊伍鏈（`+104h`），每個人都做同樣兩件事
```

**運算元 3 被取出來但從沒被讀**。

## 錢（overlay-07 entry 28，`1CE8h`）

七種貨幣（`+88h` 起七個 word）逐個乘上 `factor` 再寫回去。

`87 00 48 00 00 00` 是 Turbo Pascal 六位元組實數的 100.0（指數 87h ＝ 135，
偏移 129 → 2^6；尾數 48h 加隱含的前導 1 → 1.5625 × 64 ＝ 100），所以那一步
就是除以 100。

**待證**：實數轉回整數那一步（`05BBh:0C72h`，沒有符號名）是截去還是四捨
五入。兩者最多差一枚硬幣。實作照截去。

## 物品（overlay-07 entry 29，`1E17h`）

走角色的物品鏈（`+C8h` 起，`+2Ah` 是下一件），每一件：

```
1E38h  重量（`+37h` word）> FFh → 成功率 −= 5Ah（不足就歸零）
       否則 > 18h        → 成功率 −= 32h（不足就歸零）
1E7Dh  骰(1, 100)
1E9Ah  骰值 ≤ 成功率 → 移除這一件（overlay-25 entry ?，`010Ah:0075h`）
```

兩件事要照做：

1. **先扣成功率再擲**，扣的那一下對當件也生效。
2. **扣下去不會回復**。那個成功率是傳值進來之後**就地改掉**的參數，所以
   背包裡先出現的一件盔甲會讓後面每一樣東西都比較難被偷。少了這一條，
   小偷會偷走比原版多得多的東西，而那在測試報表上看起來只是「隨機」。

界線是「大於」不是「大於等於」：重量剛好 18h 不扣。
