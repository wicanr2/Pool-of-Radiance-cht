# Spec 121：盤面上的雲團物件

狀態：READY（節點版面、四格形狀、蓋／收／還原／重疊重蓋）；
DRAFT（每回合對站在裡面的人做什麼、誰來呼叫、`1Fh` 那一組物件是什麼）。
日期：2026-09-05。

## 為什麼要獨立一份

臭雲術與迷霧術不是「對目標下效果」，是**在戰術盤上生一個活的物件**。
remake 的戰鬥原本只有掛在人身上的效果串列（spec 069），沒有「留在盤面、
蓋住地形、收起來要還原、彼此會重疊」的東西——那是這兩支法術接不上來的
真正原因，不是缺一條公式。

## 節點版面（exact，overlay-12 `0CDEh`）

19 bytes（`5BBh:329h` 配、`5BBh:364h` 放，大小 `13h`）：

| 位移 | 內容 |
|---|---|
| `+0`..`+3` | 施法者的記錄遠指標 |
| `+4`..`+7` | 下一個節點 |
| `+8`..`+0Bh` | 四格各自原本的地形 |
| `+0Ch`..`+0Fh` | 四格各自「蓋不蓋得住」 |
| `+10h`／`+11h` | 雲心 X／Y |
| `+12h` | 這是這個施法者的第幾團雲 |

串列頭在 `DS:6CAFh`，`+4` 是下一個。

## 形狀是 2×2

原版的迴圈索引從 1 跑到 4，用到 `DS:28A7h` 的 `[1..4]` ＝ `08 02 03 04`，
配九方向的位移表 `DS:274Ah`／`DS:2753h`：

| 方向 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| dX | 0 | +1 | +1 | +1 | 0 | −1 | −1 | −1 | 0 |
| dY | −1 | −1 | 0 | +1 | +1 | +1 | 0 | −1 | 0 |

所以四格是**雲心、東、東南、南**——一個乾淨的 2×2。
（spec 098 先前寫「五格，多一格西南」，那是把不在窗內的 `DS:28A7h[5]`
也算進去了。）

## 蓋與收

- 蓋：四格裡「蓋得住」的寫地形 `1Eh`。
- 收（overlay-12 `0DCEh`..`0F0Ah`）：
  1. 掃 `DS:6634h` 那張表（筆數 `DS:6673h`，每筆 7 bytes：`+0..+3` 遠指標、
     `+4` X、`+5` Y）看這一格上有沒有別的物件。
  2. 有 → 寫 `1Fh`；沒有 → 從節點 `+8+i` 取回原地形寫回去。
  3. 把節點摘掉並釋放。
  4. **再走一遍剩下的雲，把它們的四格重新蓋成 `1Eh`**。

第 4 步就是重疊的處理方式：共用的格子在第 2 步被還原掉了，不重蓋會在另一團
中間開一個洞。

## 契約

1. `gamepack.Cloud` 保存施法者序號、雲序號、雲心與四格的「蓋得住」與原地形。
   `CellAt` 用上面那張位移表算座標，索引超出 0..3 就失敗。
2. `CloudList.RemoveAt` 依上面四步收雲；盤面那一面用 `TerrainWriter`
   （`SetTerrain` 與 `Occupied`）表示，engine／前端各自實作。
3. `CountFor` 是生新雲時的編號來源（原版走一遍串列數自己的雲）。

## 驗收

- `TestCloudCoversTheTwoByTwoBlock`：四格就是雲心、東、東南、南。
- `TestCloudStampAndRemoveRestoreTerrain`：蓋寫 `1Eh`、收還原原地形、
  那一格有別的物件就寫 `1Fh`、蓋不住的格子不寫。
- `TestRemovingOneCloudRepaintsTheOthers`：兩團重疊時收掉一團，共用的格子
  仍是 `1Eh`，只屬於被收那一團的格子才還原。
- `TestCloudListCountsPerCaster`：逐施法者的雲數與查找。

## 地形 `1Eh`／`1Fh` 在格位類別表裡長什麼樣

那張表就是 spec 053 的 `DS:2758h` 66×4（欄名沿用該規格）：

| 地形 | `EntryThreshold` | `PathByte1` | `PathByte2` | 第四欄 |
|---|---|---|---|---|
| `1Eh`（雲）| `01h` | `00h` | `00h` | `26h` |
| `1Fh`（另一組物件）| `01h` | `00h` | `00h` | `27h` |

`EntryThreshold` 是 `01h` 不是 `FFh`——**雲不擋路**，走得進去。
第四欄是傳給格位繪製服務的那一欄（spec 053），`26h`／`27h` 落在
第 0 帶（`01h..2Dh`）的範圍內，與 spec 120 的符號帶對得起來。

所以「站在雲裡會怎樣」不會是移動被擋，只可能是回合結算時另外做的事
——那一段還沒讀。

## 誰讀地形 `1Eh`：範圍縮到三處

把 38 支 overlay 的位元組全掃一遍，找「拿一個位元組和 `1Eh` 做比較」的指令
（`workplace/cmpscan`，一次性工具），整包只有 **8 處**，其中五處可以先排除：

| 位置 | 是什麼 | 判斷 |
|---|---|---|
| overlay-12 `2E07h` | `Roll(1,100)` 之後 `cmp al, 1Eh` | **不是地形**，是三成機率；命中就清掉效果 `0Bh`（魅惑）與 `35h`（催眠）|
| overlay-32 `0DBBh`／`0DC5h`／`0DD0h` | `cmp [bp-4], 1Eh`／`cmp es:[di], 1Eh`／`mov es:[di], 1Eh` | 蓋與還原地形本身 |
| overlay-32 `0F9Ch` | 同一支的另一半 | 同上 |

剩下三處才是「讀到雲之後做別的事」：

| 位置 | 位元組 | 樣子 |
|---|---|---|
| **overlay-24 `0B11h`** | `80 7E FF 1E  74 03  E9 2D 01` | `cmp byte [bp-1], 1Eh`；命中之後 `0B20h` 推 `1Eh` 呼叫 `010A:00A7` |
| overlay-22 `1C93h` | `80 7E F1 1E  74 03  E9 FA 00` | 法術那一支裡的「目標格是雲」分支 |
| overlay-09 `073Ah` | `80 7E F7 1E  75 6E` | 不等就跳過；相等時推 `20h` 呼叫 `010A:00A7` |

### 那兩處在做什麼：查身上有沒有某個效果

`010Ah:00A7h` 不必再猜——**它就是效果串列的線性搜尋**（spec 069 的
「以效果代碼從頭線性搜尋」，spec 078 也引到同一支）。`010Ah` 是 overlay-25
（spec 109）。所以兩處的形狀都是「這一格是雲 → 查這個記錄身上有沒有某個效果」：

```
overlay-24 0B0Ch  lcall 013D:007F          ; 取這一格的兩個位元組到 [bp-1]／[bp-2]
         0B11h  cmp byte [bp-1], 1Eh     ; 地形是雲嗎
         0B15h  je 0B1Ah                 ; 不是就 jmp +12Dh 整段跳過
         0B1Ah  push [bp+8] / [bp+6]     ; 記錄的遠指標
         0B20h  mov al, 1Eh / push ax    ; **要找的效果代碼 1Eh**
         0B23h  lea di, [bp-6] / push ss / push di
         0B28h  lcall 010A:00A7          ; 效果串列搜尋
         0B2Dh  or al, al / jz ...
```

```
overlay-09 0728h  mov al, [di+2758h]      ; 格位類別表（spec 053）
         073Ah  cmp byte [bp-9], 1Eh     ; 地形是雲嗎
         073Eh  jne +6Eh
         0746h  mov al, 20h / push ax    ; **要找的效果代碼 20h**
         074Eh  lcall 010A:00A7
         0753h  or al, al / jnz +57h
```

overlay-09 那一支前面剛讀完格位類別表，所以它在**移動／接近**的迴圈裡；
overlay-24 那一支在套用傷害與效果的 overlay 裡。

**所以雲對人的作用是透過效果代碼 `1Eh`／`20h` 走的**，不是收雲那一支。
`1Eh` 在 spec 112 的分派表裡出現在**群組 11**（`21h 11h 08h 09h 2Dh 2Eh 1Eh`）
與**群組 15**（`15h 1Eh 4Ah 4Bh 0Bh`），而這兩組的呼叫端**還沒讀**——
下一步就是那兩個呼叫端，以及 `013D:007F`（取格子那兩個位元組的那一支）。

## 仍未閉合

- **站在雲裡的人會怎樣**。收雲那一支完全不碰任何人的記錄；候選已經縮到
  上面那三處（overlay-24 `0B11h` 優先）。
- 每回合誰來呼叫這一支。
- `DS:6634h` 那組（地形 `1Fh`）是什麼物件。

在這三項讀出來之前，臭雲術與迷霧術**還不算接完**——盤面物件有了，
但它對人沒有作用。
