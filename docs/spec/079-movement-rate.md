# Spec 079：移動力

狀態：CONFORMED（基礎值、重算常式、盔甲與負重兩條規則、力量的重量寬容；
七名預設人物的 `+11Ch` 逐一算得出來）。日期：2026-09-03。

## 為什麼需要它

`29h ENCOUNTER MENU`（spec 078）的逃跑判定要拿**隊伍最慢**的移動力和運算元
13 比，逼近判定拿**最快**的和運算元 14 比。算移動力的 `1F87h` 逐人讀記錄
`+11Ch`，所以這個欄位是那條 opcode 的前置條件。

## 三段管線

順序不能換：重設 → 盔甲 → 負重。

### 一、重設：`+11Ch = +72h`

overlay-25 `0E36h` 那一段把四對「基礎／目前」欄位一起抄回去：

| 寫入 | 來源 | 意義 |
|---|---|---|
| `+101h` | 常數 0 | 豁免修正（spec 075）|
| `+111h` | `+A9h` | 內部 AC ← 基礎 AC |
| `+11Ch` | `+72h` | 目前移動力 ← 基礎移動力 |
| `+110h` | `+2Dh` | 內部 THAC0 ← 基礎 THAC0 |

`+72h` 是 12：建角常式（overlay-16 `1C0Bh`）與 overlay-12 `0B96h` 都寫 12，
七名預設人物的 `+72h` 全是 12。Animate Dead 叫起來的不死生物寫 6
（overlay-22 `2115h`）。

### 二、盔甲：overlay-25 `01F8h`

一次一件物品。先查物品型別表（`DS:54E0h + 型別 × 16` 的第 0 個 byte，
spec 065）：**不是類別 2 就直接返回**，所以只有盔甲影響移動力。

| 物品 `+37h` 的重量 | 移動力 |
|---|---|
| 0..150 | `+72h`（12）|
| 151..399 | 9 |
| 其餘（含負值）| 6 |

之後如果物品 `+32h` 的加值不為零、而且算出來 ≤ 9，就再 +3——魔法盔甲等於
輕一級。常式本身不看 `+34h`（穿戴中）旗標，是呼叫端挑物品；沒穿在身上的
盔甲不該拖慢腳步，所以 remake 只對穿戴中的算。

### 三、負重：overlay-25 `039Fh`

輸入是 `+102h` 的總負重**減掉力量的重量寬容**，負值先夾成 0。

總負重自己由 overlay-25 `0C17h` 起那段迴圈累加：走物品鏈（`+C8h` 起、
`+2Ah` 是 next），每件加「重量 × 數量」（數量 0 當 1），**再加上身上所有
硬幣的枚數——一枚就是一單位**。七種貨幣的枚數在原版記錄的 `+88h` 起，
七個 word（spec 040 的七種幣別）。

| 減完之後 | 移動力 |
|---|---|
| 0..512 | 維持 |
| 513..768 | 9 |
| 769..1024 | 6 |
| 1025 以上 | 3 |

**只會往下壓**（`cmp; jae` 之後才寫），不會把盔甲壓低的值調回去。

## 力量的重量寬容：`13F8h`

索引由 `1203h` 給，與 spec 063 的力量表索引同一套（0..17 就是力量本身；
18 依例外力量分成 18、19、20、21、22、23）。

| 索引 | 寬容 |
|---|---|
| 1..3 | −350 |
| 4..5 | −250 |
| 6..7 | −150 |
| 8..11 | 0 |
| 12..13 | +100 |
| 14..15 | +200 |
| 16 | +350 |
| 17..21 | `500 + (索引−17) × 250` |
| 22..26 | `2000 + (索引−22) × 1000` |
| 27 | 7500 |
| 28..30 | `9000 + (索引−28) × 3000` |

所以 18/00 是 750、18/01 是 1000、18/100 是 3000。

## 七名預設人物逐一對得上

`internal/gamepack.MovementRate` 從原始 `.sav` 與 `.itm` 位元組算，
結果與記錄裡已經存好的 `+11Ch` 完全相同：

| 記錄 | 盔甲 | 負重 − 寬容 | 算出來 | `+11Ch` |
|---|---|---:|---:|---:|
| `chrdatd1` | Plate Mail +3（300，有加值）→ 12 | 4044 − 3000 = 1044 | 3 | 3 |
| `chrdatd2` | 450 有加值 → 6+3 | 3351 − 3000 = 351 | 9 | 9 |
| `chrdatd3` | 450 有加值 → 6+3 | 3122 − 3000 = 122 | 9 | 9 |
| `chrdatd4` | 150 → 12 | 2742 − 3000 → 0 | 12 | 12 |
| `chrdatd5` | 無 | 4031 − 3000 = 1031 | 3 | 3 |
| `chrdatd6` | 無 | 2249 − 750 = 1499 | 3 | 3 |
| `chrdatd7` | 150 無加值 → 12 | 270 − 1000 → 0 | 12 | 12 |

三段管線少任何一段都會有人對不上：沒有盔甲的 +3，`chrdatd2`／`chrdatd3`
會變成 6；沒有力量寬容，`chrdatd4` 會變成 3。

## 硬幣佔的重量不能省

七名預設人物的物品重量只有 255..1325，`+102h` 卻是 270..4044——差額
1994..3084 全部來自硬幣，而且逐一精確相符：

| 記錄 | 物品 | 硬幣 | `+102h` |
|---|---:|---:|---:|
| `chrdatd1` | 960 | 3084 | 4044 |
| `chrdatd2` | 715 | 2636 | 3351 |
| `chrdatd3` | 730 | 2392 | 3122 |
| `chrdatd4` | 270 | 2472 | 2742 |
| `chrdatd5` | 1325 | 2706 | 4031 |
| `chrdatd6` | 255 | 1994 | 2249 |
| `chrdatd7` | 270 | 0 | 270 |

少了硬幣那一項，`chrdatd1`（1044 → 3）會算成 960 − 3000 → 0 → 12，
差了整整一級。
