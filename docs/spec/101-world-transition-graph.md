# Spec 101：世界怎麼接起來——NEWECL 圖與邊界出口

狀態：READY（證據齊、工具可重跑）

## 一句話

29 個 ECL 區塊之間的連接**幾乎全部靠 `NEWECL`**，走出地圖邊界只接得起
城區與貧民窟這一對；要走到其他區，得先過碼頭那一關（spec 099）。

## 怎麼量的

`cmd/pool-world-graph` 直接讀原版 ZIP：對每一個 ECL 區塊做靜態追蹤，把
`NEWECL` 的目標與 `LOAD FILES` 的三個欄位收起來；對每一張 GEO 地圖，
把邊界上「往外沒有牆」的格子列出來，並標上它屬於哪一個**雙向連通元件**。

```
tools/go.sh run ./cmd/pool-world-graph -text
```

運算元有兩種，混在一起看會得到假結論：立即值就是區塊編號，記憶體參照寫成
`@6E79`——那是「編號存在這個變數裡」，不是「有個編號 28281 的區塊」。

## GEO：走出邊界只有一對

`cmd/pool-world-graph` 的第二段列每一張圖的邊界出口。**元件要看雙向**——
只算「走得過去」的話，一張圖的出口會全部看起來互通，實際上回不來：

| 圖 | 邊界出口 | 起點那一格所在元件裡的出口 |
|---|---:|---|
| geo3/0（城區） | 28 | **只有 (0,4)W** |
| geo2/20（貧民窟） | 3 | 進來的 (15,4)E 一個；兩個西向出口在別的元件 |

城區 28 個邊界出口有 27 個站在起點走不到——**走不到別的地方是這一張圖自己的
牆擋著**，不是機制不存在。走出邊界是**通用機制**：29 個 ECL 區塊裡有 18 個
讀 `DS:6DD5h`（ecl1/18、1/24、2/9、2/15、2/20、3/0、3/14、4/2、4/10、4/21、
5/3、5/4、5/5、5/6、6/1、6/28、7/17、8/29），見 spec 100。

## 這對「走得到多少世界」的意思

目前走得到 3 張圖、5 個 ECL block（0、8、11、20、21）。剩下的 24 個不是
被 bug 擋住，是**被劇情閘門擋住**：

```
ecl3/0 ──走路──> ecl2/20 ──走路──> ecl3/0
   │
   ├──碼頭選單 SOKAL──> ecl4/21（索寇要塞）──> ecl3/0
   └──碼頭選單 EAST/WEST/BAY──> ecl7/26、ecl8/27
                                    │
                                    └──> 0,2,10,13,14,16,17,18,22,24,25,27…
```

而 EAST/WEST/BAY 那三支被 `DS:4AA7h < 254` 擋著（spec 099），
`4AA7h` 只由索寇要塞的鬼魂那一段寫。所以**下一個要打通的是索寇要塞**，
不是再去找別的路。
