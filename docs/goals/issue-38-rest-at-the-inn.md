回一點生命力要**連續**睡滿 24 小時（288 刻）。街上每兩小時擲一次、24% 中，十二次全過只有 4%

`SAVE 200 @4A1F`、`PARTYSTRENGTH`、`GOTO 9B68h` 直接排一場隨機遭遇；實測傷兵連睡八次就是全滅。

### `4A07` 是旅店的房錢（exact，2026-09-16 讀出來）

城區地形索引 9（spec 102）那七格——GEO3/0 的 `89h`：**(4,12) (6,12) (4,13) (6,13) (0,14) (1,14) (2,14)**，
從城門 (0,4) 走街道 **12 步**就到——跑 `ecl3/0 A140h`：

```
A140  COMPARE @4A07, 0 ; IF <> ; EXIT        ; 已經有房間就不再問
A14E  PICTURE 24
A15C  PRINTCLEAR "'IT WILL COST YOU 1 PLATINUM PIECE TO REST HERE.  DO YOU WANT TO STAY?'"
A195  GOSUB AE5A → A199 ON GOTO [A1A5, AA38] ; YES／NO（YES 是索引 0）
A1A5  GOSUB A1B4      ; WHO 'WHO WILL PAY?' → 扣一枚白金（`6BC3`，spec 090）
                      ;   不夠：A20Dh "YOU DON'T HAVE ENOUGH PLATINUM." 然後 EXIT
A206    SAVE 1 → 4A07 ; （在 A1B4 裡，收完錢才寫）
A1A9  GOSUB 9A63      ; ★ 城區入口 2 的本體，重算 6DD2／6DD3 → 這時 4A07 == 1，寫 0／0
A1AD  PROGRAM 9       ; 紮營（spec 081）
```

三件跟著出來的事：

1. **付完錢腳本自己重跑入口 2**（`A1A9h`），所以 `PROGRAM 9` 開的那次紮營是 0／0，睡得安穩。
2. **remake 早就接好了後半**：`ProgramCamp = 9` → `openCamp`（`program.go`），而 `openCamp`
   （#24 之後）又會跑一次入口 2，`4A07 == 1` 時答案一樣是 0／0——兩邊不打架，**不必改產品碼**。
3. **房間只管這一次**：城區地形索引 0（一般街道，185 格）跑的 `AE6Ah` 開頭就是 `SAVE 0 @4A07`，
   所以踏回街上房間就沒了，下次要再付一枚。

所以**這一輪不需要再讀原版**，缺的只有「駕駛走過去、答 YES、挑一個身上有白金的人付錢」。

  改走貧民窟或索寇打隨機遭遇也打不贏（遭遇隻數跟隊伍強度放大，實測 12～16 隻）。

## 2026-09-16 收在哪

三件都做完，#38 關。**產品碼一行都沒改**——調查那一輪判定的「`PROGRAM 9` 早就接好」是對的。

- **駕駛** `restAtTheInn()`（`mainline_rest_test.go`）：這一區會打擾 → 不在城區就先
  `walkBackToPhlan()`（貧民窟東緣 (15,4) 出界）→ `approachIfPossible` 走到旅店七格之一 →
  踏上去答 YES → `WHO WILL PAY?` 挑一個身上有白金的人 → `PROGRAM 9` 開紮營，收掉畫面讓
  原本的排時間流程接手 → 睡完 `walkBackFrom(origin)` 走回原來那張圖。走不回去、沒白金、
  或旅店不在同一張圖，一律回 false 維持「不睡、記一行」——**不硬走**。
- **測試**（`inn_rest_test.go`，收錢與開紮營不重複，那些由既有的
  `TestTheInnChargesAPlatinumAndOpensCamp` 釘著）：開房間之後 1／101 → 0／0；沒白金開不成
  而且錢一毛不少；踏回街上 `AE6Ah` 把 `4A07` 清 0、打斷設定回到 1／101。
- **治具**：`newGameAtFirstCombat` 給隊伍鏈甲＋盾＋長劍（`equipForFirstCombat`，AC 10 → 2）
  並在城區直接走向城門出界去貧民窟——城裡唯一會開打的是十四點的宵禁，而那 38 隻（含 12 名
  六級戰士）不是這個治具要量的東西。`TestQuickCombatEarnsExperience` 與
  `TestPassiveCombatTerminates` 都回綠（打 12 隻獸人，hour 0）。

**順帶學到的兩件事**（都寫進 spec 114）：

1. **睡覺要睡到早上**：天數不會改變醒來的時刻，而城裡十四點開始宵禁，所以排時間時要另外
   補小時（`hoursUntilMorning`，目標六點）。
2. **房間只管一次**：踏回街上就被 `AE6Ah` 清掉，連睡兩晚要付兩枚。

**探針**：house rule 那一條的 seed 從 139 換成 143（駕駛一改骰流就跟著變，#37 的 goal 早就
提醒過要重掃）。143 會打贏諾里斯並用到旅店（playtest 補八），但走回市政廳的路上在城區 (3,4)
全滅——**時刻與宵禁的關係還沒查**，那是 #22／#26。補七那一版的「A 升二級、B 買板甲」收據
這一輪沒有重現，數字留在補七。

全套測試回到既有的五條紅（索寇、世界巡迴、自己玩、兩條主線探針），#24／#20 那一輪多出來的
