## 為什麼這三條放同一輪

三條都是**現況斷言**：README 說「做到哪」、對拍表說「離原版多遠」、截圖說「長什麼樣」。
三份都有同一個毛病——**沒有人拿它們去對現在的程式**，所以錯的方向都是「看起來保守」而不是「看起來錯」：

- README 還寫著「主線沒有從開場到結局連續跑過一次」，而 #5 兩邊都作弊跑完並逐段對照過了（2026-09-17）。
- 對拍的十項差是與 `docs/audit/dos-parity-sample.md` 比出來的，那張表是 **v.1.1.5** 產的；
  歷輪 commit 寫的「不變 33」是跟**上一次跑的結果**比，所以漂移一路沒有開口。
- 戰利品畫面已經補到原版口徑，但沒有一張 remake 的截圖擺在原版旁邊。
