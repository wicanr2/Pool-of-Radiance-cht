這份表記錄當年官方譯本實際印出的用字，不做統一；`異名` 欄列出同一對象在書中
出現過的其他譯法，供 remake 決定採用哪一個時有依據。依 AGENTS §8，未經本作
證據支持前，不得改用 CoAB 的譯名。

## 法術（附錄 2，p.49）

牧師：祈禱／詛咒、治療輕傷／引起輕傷、搜尋魔法物品、免於邪惡入侵／免於善良的侵害、
發現陷阱、束縛、耐火術、在 15 步內抑制敵人施展魔法、減慢毒藥毒性之發作、蛇魅術、
心靈之鎚、活動死屍、治療失明／引起失明、治療疾病／引起疾病、解除魔法、
移去詛咒／散佈詛咒。

魔術師：燃燒之手、迷惑術、搜尋魔法物品、巨大／縮小、免於邪惡入侵／免於善良侵害、
魔法飛彈、讀魔法術、魔盾術、防護罩、電擊術、催眠術、搜索隱藏物、隱身術、開鎖術、
幻像術、衰弱術、臭雲術、大力術、閃爍術、解除法術、火球術、迅速移動、綑綁術、
閃電術、可避免被一般飛彈擊中、減緩術。
