## 怪物

第三章的怪物一覽表（上冊 p.13–18）共 **43 種**，每一條的格式都是「英文名（羅馬數字
等級）：中文說明」——**條目名一個中文都沒有，說明文字則全是中文**。因此中文名要從
說明書自己的用字回推，分三級標示，接線時不可混用：

- `原書`：說明書某處直接用這個中文名指這種怪物。可以直接採用。
- `回推`：說明文字裡有可用的構詞成分，由此組出；依據欄註明原句與哪一段是推的。
- `待證`：說明沒有給任何中文成分，須由遊戲內文字或戰鬥訊息確認，**不得自行發明**。

## 定案譯名

說明書自身有多處同一對象兩種譯法。接線前先固定單一標準，避免同一個地名在遊戲不同

本節只約束 game pack 與 UI。

取捨依序套用四條原則，先命中者為準：

1. **出現次數多者勝。** 一次性的寫法視為當年排版或譯者的疏漏。

3. **仍相同時，內文敘述優於地圖標註。** 圖面受空間限制，且經過美術重排。
4. **仍相同時取較短者**，遊戲內文字框寬度有限。

## 與《青色枷的詛咒》對齊怪物名稱

依使用者 2026-09-02 指示，怪物名稱參考同系列的 CoAB remake（`gamepack/pack/
20-locale.zh-TW.json` 的 `combatant.*`，68 條）對齊。對齊政策，順序即優先序：

1. **Pool 說明書有原書譯名的，一律以說明書為準。** 兩作是不同譯本，Pool 玩家看的是
   軟體世界的說明書；CoAB 的差異只記錄，不覆蓋。
2. **說明書只有回推名的，改採 CoAB 譯名。** 回推是我們自己組的字，CoAB 那組已在
   同系列作品裡用過，比較通行；原表的回推依據保留，作為推導軌跡。
3. **說明書待證、CoAB 有的，採 CoAB 並標來源。** 這是本次對齊最大的收穫。
4. **兩邊都沒有的，維持待證。** 不發明。
