本程式是繁體中文 remake，不包含原版遊戲的公開散布授權。

## 要自己準備的兩樣東西

**原版遊戲資料。** 把自己合法持有的 DOS 版遊戲檔打包成
`Pool of Radiance (1988).zip`，放在執行檔或 AppImage 同一層；ZIP 內需保留
原始檔名與目錄（`poolrad/…`）。發行包不含這個 ZIP。

**倚天點陣字型。** 中文介面用的是倚天中文系統的 16×15 點陣字，屬第三方資產，
不隨發行包散布。啟動時以 `-eten-font <stdfont.15 的路徑>` 指定；同一層若有
`ascfont.15`，半形與全形標點會一併使用。

沒有指定字型時 `-lang zh` 會直接結束並說明原因，不會默默用英文跑——
中文介面缺字型時畫面會整片空白，那看起來像繪圖壞掉，不像沒有字型。

## 存檔位置

存檔預設寫到作業系統的使用者設定目錄
`pool-of-radiance-remake/state.json`，不會寫進唯讀的 AppImage 或 `.app`。
可用 `-save <路徑>` 改成其他位置。

## 常用參數

| 參數 | 用途 |
|---|---|
| `-zip <路徑>` | 原版資料 ZIP，預設是同一層的 `Pool of Radiance (1988).zip` |
| `-lang zh` / `-lang en` | 介面語言；預設 `auto`（有字型就中文） |
| `-eten-font <路徑>` | 倚天 `stdfont.15` |
| `-save <路徑>` | 存檔檔案 |

遊戲中 `F1` 是說明，`J` 開探險者手冊，`I` 開裝備頁，`F10` 存檔並離開。
