# 這一份是**本機完整版**，帶配樂——不要散布

裡面多了六個 OGG，放在執行檔旁邊的 `music/`。遊戲啟動時會自己找到那個目錄；
要放在別的地方就用 `-music-dir <路徑>`。

## 曲子是哪裡來的

原版 **DOS 版沒有音樂**，只有 PC 喇叭。有音樂的是 **Amiga 版**
（1990，U.S. Gold／S.S.I.），作曲 **Wally Beben**。這六首是他寫的那一個
自訂播放器模組裡的六首 subsong，以 UADE 渲染成 44.1 kHz 立體聲再轉 Ogg Vorbis。

## 什麼時候放

預設是 `-music-mode original`：**只有標題有音樂**。

那不是省事，是量出來的。C64 版（唯一手上既有音樂又能跑的原版）在模擬器裡錄
下來量，標題那兩分鐘是 −35 dBFS 的音樂，進遊戲之後掉到 −78 dBFS——等同靜音，
只有偶發的短音效。檔案佈局也對得上：`MUSIC` 只在開機那一面。

想讓地圖與戰鬥也有音樂，用 `-music-mode full`：

| 情境 | subsong | 說明 |
|---|---:|---|
| 標題／隊伍管理 | 1 | 六首裡唯一夠長又會循環的 |
| 在地圖上 | 6 | **原版是靜的**，這一首是這個 remake 自己配的 |
| 戰術戰鬥 | 4 | **原版是靜的**，同上 |

Amiga 版有六首，只用一首說不過去；但那六首在 Amiga 版實際放在哪裡，
沒有那一版的遊戲程式就核對不了，所以那兩列是選擇不是還原。
